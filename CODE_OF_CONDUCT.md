# Code of conduct

ExScreenHelp follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in this project's issues, pull requests and other spaces is expected to follow it.

In short: be respectful and welcoming, assume good intent, and keep criticism about the work, not the person. Harassment, insults and personal attacks aren't tolerated, whoever they come from.

## Reporting

If someone's behaviour here makes you uncomfortable, you can tell the maintainer privately using GitHub's private reporting form:

**[Report privately](https://github.com/jerungpyro/ExScreenHelp/security/advisories/new)**

The form is meant for security problems, but it's the private channel this project has. Start the title with "Conduct report" so it's handled as one. For anything that isn't sensitive, you can also [open an issue](https://github.com/jerungpyro/ExScreenHelp/issues/new/choose).

Reports are kept confidential. The maintainer will look into every report and respond in line with the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): from a private word, through a warning, to a temporary or permanent ban from the project.
